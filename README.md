# MaybeTask

Приложение для небольших команд, которое превращает задачи в договорённости с наградой, внутренней валютой.
Не просто список дел, а система ответственности: задачи принимаются как контракты, выполняются в срок и приносят баллы или бонусы.
Приложение помогает договариваться без конфликтов, мотивирует и формирует привычку доводить дела до конца.
